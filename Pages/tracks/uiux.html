Track Overview

UI/UX Design combines visual design with user experience research to create digital products that are both beautiful and functional. This track will teach you how to design intuitive interfaces, conduct user research, build prototypes, and create comprehensive design systems.

You'll master design tools like Figma and Adobe XD, learn fundamental design principles, understand user psychology, and develop skills in wireframing, prototyping, and usability testing. By the end of this track, you'll be able to create compelling digital experiences that solve real user problems.
